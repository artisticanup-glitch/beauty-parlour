# /awwwards — Creative Web Architect Skill

Installed from GitHub (`Z4YT0N/awwwards-skill`).

## Usage

Read [reference/awwwards.md](reference/awwwards.md) for the full creative direction, commands, anti-AI-slop rules, typography, color contrast philosophy, performance budgets, micro-interactions, and self-validation checklist.

Available sub-commands documented in `reference/awwwards.md`:
- `/awwwards` — Smart onboarding (detects project state and guides next steps)
- `/awwwards mix [description]` — Creative direction + tech recipe
- `/awwwards scan [url]` — Analyze any live website (stack, tokens, techniques, fonts)
- `/awwwards analyze [path]` — Analyze existing project → docs + tokens + fixes
- `/awwwards review [path or description]` — Honest design + UX + copy review
- `/awwwards palette [description]` — Generate color system with contrast ratios
- `/awwwards create [description]` — Full build: design system + docs + code
- `/awwwards prototype [description]` — Quick HTML mockup
- `/awwwards why [decision]` — Explain any design/tech decision in depth
